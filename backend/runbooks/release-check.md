# Runbook — Pre-Submission Release Check

## Clone and build

- [ ] Fresh clone on a clean directory.
- [ ] Install from committed lockfiles.
- [ ] Apply migrations/seed from docs.
- [ ] Start web/API using documented commands.
- [ ] No undeclared local file dependency.

## Functional path

- [ ] Sign in.
- [ ] Upload synthetic SLA.
- [ ] Extraction/chunks persist.
- [ ] Retrieval returns valid evidence.
- [ ] Reviewer/Skeptic/Supervisor turns persist and stream.
- [ ] At least one fixture reaches consensus.
- [ ] At least one fixture escalates after the cap.
- [ ] Citation click opens the correct evidence.
- [ ] Markdown/PDF export works.

## Reliability/security

- [ ] Malformed model output is rejected/retried safely.
- [ ] Prompt injection fixture is ignored as instruction.
- [ ] Cross-user audit access fails.
- [ ] No secret appears in client bundle, repo or logs.
- [ ] Delete flow removes private vectors/storage as documented.
- [ ] External-service outage shows degraded/error state.

## Evidence and claims

- [ ] Accepted finding citation validity = 100% in evaluation.
- [ ] README metrics were generated by the harness.
- [ ] Source snapshot/provenance is visible.
- [ ] Legal disclaimer appears in app and report.
- [ ] No claim of comprehensive legal coverage.

## Demo

- [ ] Embedding model cached.
- [ ] Demo PDF and policy included.
- [ ] 4-minute path rehearsed.
- [ ] Prior real run available as clearly labeled contingency evidence.
