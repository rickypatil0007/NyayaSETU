# NyaySetu: Multi-Agent Legal & Regulatory Compliance Auditor
NyaySetu is an evidence-grounded, multi-agent legal and regulatory compliance auditor that retrieves authoritative legal context, independently reviews and challenges contract clauses, supervises disagreements, quantifies confidence, and escalates uncertain findings for human review.
============================================================
## Configuration Step 1: Advanced Security and Pipeline Optimization
### 1.1 Environment Variables
- `SUPABASE_URL`: MUST be set to a valid Supabase instance.
- `SUPABASE_SERVICE_KEY`: MUST NOT be exposed to the client.
- `PINECONE_API_KEY`: MUST be scoped to the specific index.
- `HUGGINGFACE_TOKEN`: MUST be provided for embeddings.
### 1.2 Deployment Constraints
- The system MUST run in a controlled Vercel environment.
- Edge functions SHOULD be used for agent routing to minimize latency.
### 1.3 Testing & Validation
- Run `npm run test:e2e` to validate the RAG pipeline.
- Ensure synthetic dataset {i} passes before merging.
### 1.4 Security Limitations
- The system MUST NOT provide binding legal opinions.
- It MUST state that findings are for informational/audit purposes only.
