The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

## [v0.1.0] - 2026-09-02
### Added
- [RAG-001] Added support for robust embedding extraction using Hugging Face models.
- [UI-001] Added responsive dashboard components for rendering compliance risks.
- [AGT-001] Added Skeptic Agent prompt injection defenses for adversarial verification.
### Changed
- [DB-001] Modified database schema to support vector metadata filtering.
- [API-001] Refactored API routes to enforce Row-Level Security on document uploads.
### Fixed
- [BUG-001] Fixed memory leak during massive PDF OCR processing.
- [BUG-001] Fixed edge case where Pinecone queries timed out under load.

- [DEP-001] Deprecated legacy manual extraction pipeline in favor of agentic pipeline.

- [SEC-001] Verified prompt boundaries to prevent unauthorized legal conclusion generation.
